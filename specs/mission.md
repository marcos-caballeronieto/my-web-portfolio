# Core Mission: The Dynamic Engineering Hub

## Vision
To create a high-performance, aesthetically stunning web portfolio that showcases the intersection of **Biomedical Engineering**, **Mechanical Engineering**, and **Software Development**. This hub is not just a repository of projects, but a demonstration of technical problem-solving and modern UX design.

## Target Audience
- Technical recruiters and hiring managers.
- Potential academic collaborators and research institutions.
- Fellow engineers and developers looking for inspiration.

## Strategic Objectives
1. **Showcase Technical Depth**: Use Mermaid.js and Markdown to document complex engineering systems clearly.
2. **Prioritize Performance**: Maintain a fast-loading, lightweight frontend (Vanilla JS / Bootstrap).
3. **Bilingual Accessibility**: Provide a seamless, zero-reload experience for both English and Spanish speakers, in the 'about me' section.
4. **Interactive Engagement**: Use subtle animations (Particles.js) and responsive elements to create a "living" portfolio.

## Core Values
- **Clarity over Complexity**: Engineering projects must be explained simply but with detail available.
- **Visual Impact**: First impressions matter; the UI must feel premium and "high-tech".
- **Dynamic Content**: Data is managed via a custom Django CMS to ensure the portfolio is always up-to-date.
